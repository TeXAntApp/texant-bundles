# TeXAnt Bundles & Distribution Assets

This repository hosts pre-built TeX Live collection and bundle archives, OCR models, and distribution manifests for the [TeXAnt](https://github.com/TeXAntApp) application.

## Release Assets

All runtime ZIP archives are distributed via [GitHub Releases](../../releases).

- **Bundles:** `minimal-bundle.zip`, `recommended-bundle.zip`, `extended-bundle.zip`
- **Collections:** `collection-*.zip` (32 modular TeX Live collection archives)
- **OCR Models:** `pix2text-mfr-ocr-models.zip`, `pix2text-mfr-ocr-models-full.zip`
- **Manifests:** `manifest.json`, `zip-manifest.json`, `release-manifest.json`, `SHA256SUMS`
